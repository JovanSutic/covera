**Touch.** `src/hooks/useReservationActions.ts` (edit)

**Do.** *(logic mode — the wiring is the decision)*

The hook already owns the reservation actions. It gains the sibling list and the two new windows,
and it must read them from `actionWindows` rather than from `reservationActions` (which keeps its
own three rules for the table's kebab — untouched).

Add to `UseReservationActionsParams`:

```ts
  /** D14: every reservation for the same apartment, including this one. */
  siblings?: readonly SiblingStay[];
  /** D16: whether the claim on this stay has been filed. */
  claimFiled?: boolean;
```

Inside the hook, after the existing `rules` computation:

```ts
  // D13: the four windows from the ONE helper. `now` is the same render-time value the proof
  // window above was computed with (invariant 10) — this is not a second clock.
  const actionWindows = getActionWindows({
    reservation: { ...reservation, claimFiled },
    siblings: siblings ?? [],

  });
```

and return it alongside the existing keys:

```ts
    actionWindows,
```

Add the imports:

```ts
import { getActionWindows } from "@/lib/helpers/actionWindows";
import type { SiblingStay } from "@/lib/helpers/actionWindows";
```
