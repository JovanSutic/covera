# p1 — Baseline repair

**Prerequisite:** none (this is the first phase)
**Gate:** `npm run gate`

## Why this phase exists

The regenerated API client (uncommitted in the tree) added `photoAllowance` as a
**required** field on `IncidentItem`, `IncidentItemWithToken` and `FieldIngest`. Ten
existing test files build those shapes and now fail `tsc -b`, so the gate is red before
any feature work begins. Nothing can be verified against a red gate.

Adopting the regeneration is deliberate (D1): the spec's §Data depends on it, and it is
generated output — editing it by hand is invariant 1's violation and would be destroyed by
the next `npm run api:generate`.
