# p3 — Message rewrites (prep 4)

**Prerequisite:** p1 (gate green)
**Gate:** `npm run gate`

## Why this phase exists

Two messages the app generates for the host to send:

- **Prep 4a.** The guest inspection message carries a **relative** path
  (`/inspection/<id>`). The host pastes it into an email or a chat, where a relative URL
  resolves against the *reader's* origin — or nothing at all. It must be absolute.
- **Prep 4b.** The claim message reads like a demand. The host is writing to a guest they
  expect to cooperate, so the register must invite rather than accuse.

There are **two** places that build the guest URL, and both must change:
`useReservationActions.ts` (the table's kebab popover) and `ReservationPage.tsx` (the
section). They already share the template, so they must share the fix.

## Step 3.1 — Add the `absoluteUrl` helper

**Touch:** `src/lib/helpers/absoluteUrl.ts` (create), `src/lib/helpers/absoluteUrl.test.ts` (create)

**Do:**
A pure helper rather than a `window` read inside a component (D12): pure code is testable
without jsdom globals, and the caller passes the origin in.

Create `src/lib/helpers/absoluteUrl.ts`:

```ts
/**
 * D12/prep 4a: the URL the host PASTES somewhere else.
 *
 * `buildPath` returns an app-relative path (`/inspection/<id>`), which is right for a
 * `<Link>` and wrong for a message: the host sends this to a guest by email or chat, where
 * a relative URL resolves against the reader's own origin — or against nothing. The guest
 * then has a dead link and the host has no way to know.
 *
 * `origin` is a parameter rather than a `window.location.origin` read so this stays pure
 * and testable, and so the caller is visibly responsible for the value (the component reads
 * `window.location.origin` once).
 *
 * An already-absolute URL is returned unchanged: the caller may hand this a path that
 * `withLang` or a future helper already made absolute, and prefixing it again would produce
 * `https://a/https://b`.
 */
export function absoluteUrl(path: string, origin: string): string {
  if (/^[a-z][a-z0-9+.-]*:\/\//i.test(path)) return path;

  const base = origin.replace(/\/$/, "");
  const suffix = path.startsWith("/") ? path : `/${path}`;

  return `${base}${suffix}`;
}
```

Create `src/lib/helpers/absoluteUrl.test.ts`:

```ts
import { describe, expect, it } from "vitest";

import { absoluteUrl } from "./absoluteUrl";

describe("absoluteUrl", () => {
  it("prefixes an app-relative path with the origin", () => {
    expect(absoluteUrl("/inspection/abc", "https://app.covera.test")).toBe(
      "https://app.covera.test/inspection/abc",
    );
  });

  it("preserves a query string", () => {
    expect(absoluteUrl("/inspection/abc?lang=de", "https://app.covera.test")).toBe(
      "https://app.covera.test/inspection/abc?lang=de",
    );
  });

  it("does not double the slash when the origin ends with one", () => {
    expect(absoluteUrl("/inspection/abc", "https://app.covera.test/")).toBe(
      "https://app.covera.test/inspection/abc",
    );
  });

  it("adds the leading slash when the path lacks one", () => {
    expect(absoluteUrl("inspection/abc", "https://app.covera.test")).toBe(
      "https://app.covera.test/inspection/abc",
    );
  });

  it("leaves an already-absolute URL alone", () => {
    expect(absoluteUrl("https://other.test/x", "https://app.covera.test")).toBe(
      "https://other.test/x",
    );
    expect(absoluteUrl("http://other.test/x", "https://app.covera.test")).toBe(
      "http://other.test/x",
    );
  });
});
```

- `npx vitest run src/lib/helpers/absoluteUrl.test.ts` → 5 tests pass ✓
- `grep -c "export function absoluteUrl" src/lib/helpers/absoluteUrl.ts` → `1` ✓

## Step 3.2 — Absolutize the kebab-popover URL

**Touch:** `src/hooks/useReservationActions.ts` (edit)

**Do:**
`guestInspectionUrl` is consumed only by `GuestInspectionMessage`, which renders it into the
message the host copies — so it is a pasted URL and must be absolute (prep 4a). Change the
computation to go through the helper:

```ts
  // Prep 4a: this URL is PASTED into an email or chat, not clicked in the app, so it must
  // be absolute — a relative path resolves against the reader's origin, or against
  // nothing. `window.location.origin` is read here, at the one place the value is made,
  // and the helper stays pure.
  const guestInspectionUrl = inspectionId
    ? absoluteUrl(
        buildPath(appPaths.inspection, { id: inspectionId }),
        window.location.origin,
      )
    : "";
```

Add the import:

```ts
import { absoluteUrl } from "@/lib/helpers/absoluteUrl";
```
