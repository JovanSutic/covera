# p4 — Access links: mint and revoke (prep 5)

**Prerequisite:** p1, p3 (p3 edits `ReservationPage.tsx`, which this phase also edits)
**Gate:** `npm run gate`

## Why this phase exists

Prep 5 and the Feature section: a host with several apartments cannot always be on site. They
need to mint a short-lived link and send it to a photographer or cleaner who has no account.

**Only `scope: "inspection_proof"` is offered** (D18). `damage_evidence` is in the API enum
but no endpoint accepts it — probed 2026-11-23 — so a `damage_evidence` link would open
nothing. The guest side of what this link unlocks is p7.

## Step 4.2 — The special-access module

**Touch:** `src/lib/api/specialAccess.ts` (create)

**Do:**
A write module flat in `src/lib/api/`, following `incidentClaims.ts`'s precedent (D17):
plain async functions, not `ResourceDefinition`s, because a prefetch of a write is
meaningless.

Create `src/lib/api/specialAccess.ts`:

```ts
import {
  deleteSpecialAccessByAccessId,
  postSpecialAccess,
} from "@/api/generated/requests/sdk.gen";
import type {
  CreateSpecialAccess,
  SpecialAccess,
} from "@/api/generated/requests/types.gen";
import { withAuth } from "@/lib/api/api";

/**
 * Access links (prep 5 / the Feature section).
 *
 * A host mints a short-lived `accessId` and sends the resulting URL to someone with no
 * account — a photographer collecting the pre-state proofs, or a cleaner collecting damage
 * evidence. The 32-hex id travels as a QUERY PARAMETER on the read it unlocks:
 *
 *     /inspection-guide/<apartmentId>/<reservationId>?accessId=<hex32>
 *
 * VERIFIED 2026-11-23 by probing the live API: `?accessId=x` is handled as an access attempt
 * (an unknown id answers 500) while `?foo=bar` is not (401 AUTH_TOKEN_MISSING). The
 * generated endpoint types pin `query?: never`, so passing it needs the `as never` cast
 * below — and the `url:` override does NOT compile (TS2353), which is why the cast is used
 * rather than a hand-built URL.
 *
 * ONLY `inspection_proof` is offered by the UI. `damage_evidence` is in the `AccessScope`
 * enum but NO endpoint accepts it, so a link minted with it would open nothing.
 *
 * The write calls authenticate with `withAuth()` — only a signed-in host mints a link. The
 * anonymous side is the GUEST's read, which lives in the access-aware fetchers (p7).
 */

export interface CreateAccessLinkInput {
  /** Only `inspection_proof` is offered — see the module note. */
  scope: "inspection_proof";
  reservationId: string;
  /**
   * Omitted by default so the backend's own default (12, range 1–72) applies. Sending a
   * hardcoded 12 would duplicate the server's rule and drift from it silently.
   */
  expiresInHours?: number;
}

export async function createSpecialAccess(
  input: CreateAccessLinkInput,
  signal?: AbortSignal,
): Promise<SpecialAccess | undefined> {
  const config = await withAuth(signal ? { signal } : {});
  const body: CreateSpecialAccess = {
    scope: input.scope,
    reservationId: input.reservationId,
  };

  if (input.expiresInHours !== undefined) {
    body.expiresInHours = input.expiresInHours;
  }

  const response = await postSpecialAccess({ ...config, body });

  return response.data?.access;
}

/**
 * Revoke by the `accessId` the create call returned. There is no list endpoint, so a link
 * minted in a previous session cannot be found or revoked here — the same limit D50 records
 * for cleaner tokens (D23).
 */
export async function revokeSpecialAccess(
  accessId: string,
  signal?: AbortSignal,
) {
  const config = await withAuth(signal ? { signal } : {});
  const response = await deleteSpecialAccessByAccessId({
    ...config,
    path: { accessId },
  });

  return response.data;
}
```

## Step 4.3 — The links section component

**Touch:** `src/components/host/ReservationLinksSection.tsx` (create)

**Do (contract — the executor writes the JSX):**

Create the component. Follow `IncidentFieldLink.tsx` for the copy-to-clipboard pattern and
`SectionCard` + `ActionButton` for the shell.

**Exports:**
```ts
export function ReservationLinksSection(props: {
  reservationId: string;
  apartmentId: string;
}): JSX.Element
```

**Props:** `reservationId` — the reservation the link is scoped to. `apartmentId` — for the
invalidation of the apartment's reservation list after a revoke.

**Consumes, by exported name:**
- `createSpecialAccess`, `revokeSpecialAccess` from `@/lib/api/specialAccess`
- `QUERY_ACTIONS` from `@/lib/api/queryKeys`
- `appPaths`, `buildPath` from `@/lib/router`
- `absoluteUrl` from `@/lib/helpers/absoluteUrl` (p3)
- `SectionCard`, `ActionButton` from `@/components/shared`
- `useMutation`, `useQueryClient` from `@tanstack/react-query`; `toast` from `sonner`;
  `Copy`, `Check`, `Link2`, `Trash2` from `lucide-react`

**Local state:** `const [link, setLink] = useState<{ accessId: string; url: string } | null>(null)`
and `const [copied, setCopied] = useState(false)`.

**t() keys it renders — all under `reservationPage.links.*` (D24):**
`title`, `intro`, `create`, `creating`, `created`, `copy`, `copied`, `revoke`, `revoking`,
`revoked`, `copyError`, `createError`, `revokeError`, `label`, `expiresHint`.

**State branches it must handle:**
1. **idle** — no link this session: the `intro` line and the `create` button.
2. **creating** — `createMutation.isPending`: the button shows `creating` and is disabled.
3. **created** — `link !== null`: a readonly `<input>` holding `link.url` with `aria-label`
   from `label`, a copy button, and a `revoke` button.
4. **copied** — `copied === true`: the copy button shows `copied` and a `Check` icon; cleared
   by a 2 s `setTimeout` in a `useEffect` with cleanup, exactly as `IncidentFieldLink` does.
5. **revoking** — `revokeMutation.isPending`: the revoke button is disabled.
6. **revoked** — after a successful revoke: `setLink(null)` returns to idle, with a `revoked`
   toast.
7. **error** — both mutations' `onError` read `error?.error?.message` first and fall back to
   `createError` / `revokeError` (the backend's own sentence — D33's rule, feature/46).

**The URL it builds:** the guest-facing inspection guide, absolute:
```ts
const url = absoluteUrl(
  buildPath(appPaths.inspectionGuide, { apartmentId, reservationId }),
  window.location.origin,
) + `?accessId=${access.accessId}`;
```
`appPaths.inspectionGuide`'s pattern is `/inspection-guide/:apartmentId/:reservationId`, so
both params are required. The `accessId` is appended as a query parameter (D16) — the
transport the backend actually reads.

**Callbacks:**
- `createMutation.mutate()` → on success `setLink({ accessId: access.accessId, url })` and
  invalidate `QUERY_ACTIONS.SPECIAL_ACCESS_CREATE`; toast `created`.
- `revokeMutation.mutate(link.accessId)` → on success `setLink(null)`, invalidate
  `QUERY_ACTIONS.SPECIAL_ACCESS_CREATE` and
  `[...QUERY_ACTIONS.RESERVATIONS_GET_BY_APARTMENT, apartmentId]` (invariant 6), toast
  `revoked`.
- Copy button: `navigator.clipboard.writeText(link.url)`, then `setCopied(true)`; on failure
  toast `copyError` — `IncidentFieldLink`'s exact try/catch shape.

**Invariant it must not break:** invariant 2 — every string above goes through `t()` with the
`host` namespace; no literal English in the JSX.

**Accept:**
- `grep -c "export function ReservationLinksSection" src/components/host/ReservationLinksSection.tsx` → `1` ✓
- `grep -n "useTranslation(\"host\")" src/components/host/ReservationLinksSection.tsx` → one hit ✓
- `grep -n "absoluteUrl(" src/components/host/ReservationLinksSection.tsx` → one hit ✓
- `grep -n "accessId=" src/components/host/ReservationLinksSection.tsx` → one hit ✓
- `npx tsc -b` clean (the `t()` keys resolve at runtime, not compile time) ✓
