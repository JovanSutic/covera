Prerequisite: none. Gate: `npm run gate`.

reservation's claim section links to it in every state.

surface. D19: the link is a secondary text link, present in all four states of the claim section.

## Step 5.2 — The page

**Touch:** `src/pages/host/DamageClaimGuidePage.tsx` (new)

**Do:** create a page with this shape — the section list and the copy are fixed, the JSX is the house
pattern:

```tsx
import { useTranslation } from "react-i18next";

import PageLayout from "@/components/layout/PageLayout";
import PageTitle from "@/components/PageTitle";
import { SectionCard } from "@/components/shared/SectionCard";

const SECTIONS = ["immediate", "photos", "costs", "deadlines", "airbnb"] as const;

export default function DamageClaimGuidePage() {
  const { t } = useTranslation("host");

  return (
    <PageLayout size="lg">
      <div className="space-y-6">
        <PageTitle
          title={t("incidentPage.guide.title")}
          subtitle={t("incidentPage.guide.subtitle")}
        />

        <p className="text-sm text-gray-600 dark:text-gray-300">
          {t("incidentPage.guide.intro")}
        </p>

        {SECTIONS.map((section) => (
          <SectionCard
            key={section}
            title={t(`incidentPage.guide.sections.${section}.title`)}
          >
            <p className="text-sm text-gray-600 dark:text-gray-300">
              {t(`incidentPage.guide.sections.${section}.body`)}
            </p>

            <ul className="mt-2 list-disc space-y-1 pl-5 text-sm text-gray-600 dark:text-gray-300">
              {(
                t(`incidentPage.guide.sections.${section}.points`, {
                  returnObjects: true,
                }) as unknown as string[]
              ).map((point) => (
                <li key={point}>{point}</li>
              ))}
            </ul>
          </SectionCard>
        ))}
      </div>
    </PageLayout>
  );
}
```

The `as unknown as string[]` cast is required: `t` is typed to return a string, and the
`returnObjects` overload is not narrowed by this project's i18next configuration.

**Accept:** `npx tsc -b` → clean. `grep -n "useQuery\|useMutation" src/pages/host/DamageClaimGuidePage.tsx`
→ no match (D18: static page).

**Verify:** `npm run gate` — expect this to fail on the missing locale keys; step 5.3 adds them.

## Step 5.4 — The link component

**Touch:** `src/components/host/incident/ClaimGuideLink.tsx` (new)

**Do:** create the file with exactly this content:

```tsx
import { useTranslation } from "react-i18next";

import { AccessLink } from "@/components/router/AccessLink";
import { appPaths } from "@/lib/router";

/**
 * D19: ONE link, mounted by every state of the reservation's claim section and by the
 * claim page. The host needs the procedure before a claim exists — that is when the
 * immediate-response steps still change the outcome — so it is deliberately not
 * conditional on a claim or on its status.
 */
export function ClaimGuideLink() {
  const { t } = useTranslation("host");

  return (
    <p className="mt-3">
      <AccessLink
        to={appPaths.damageClaimGuide}
        className="text-xs font-medium text-blue-600 hover:underline dark:text-blue-400"
      >
        {t("incidentPage.guide.link")}
      </AccessLink>
    </p>
  );
}
```

`AccessLink` rather than a plain `<a>`: it is the app's only link to an app path, and it renders plain
text for a viewer who cannot open the target (access principle 4).

**Accept:** `npx tsc -b` → clean.

**Verify:** `npx tsc -b`
