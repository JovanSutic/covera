# Phase 7 — real translations, and close the docs

**Prerequisite:** phase 1 (the English keys this phase replaces) and phase 6 (the last keys, so the
run is done once).
**Gate:** `npm run gate`

Steps 7.1 and 7.2 are **one atomic change**: 7.1 deletes English text from three locales and leaves
those keys missing, and 7.2 puts translations back. Between them, invariant 2 is knowingly broken —
nothing reads these keys in a test, and `json` with a missing key just falls back to `en` at runtime,
so the window is harmless by construction, but the gate belongs at the phase boundary, not between them.

Step 7.2 is an **operator step**: `npm run i18n:translate` calls Google Translate over the network.

---

### Step 7.1 — Clear the English placeholders

**Touch.** `public/locales/de/assets.json`, `public/locales/tr/assets.json`,
`public/locales/sr-Latn/assets.json` (edit)

**Do.** In each of the three files, delete the `strip`, `review` and `leave` objects from
`shotGuide`, and delete `goToCurrent` and `takePhotoFirst` from `shotGuide.actions`. Leave
`shotGuide.actions.previous` and `shotGuide.actions.finishAndSave` in place (D23).

This is what makes step 7.2 do any work at all: `scripts/translate-locales.ts` diffs `en` against the
target and translates only the **missing** keys, so English text already present would be left exactly
as it is.

**Accept.** For each of the three locales,
`node -e "const j=require('./public/locales/de/assets.json');console.log(Object.hasOwn(j.shotGuide,'strip'), Object.hasOwn(j.shotGuide.review), Object.hasOwn(j.shotGuide.leave), Object.hasOwn(j.shotGuide.actions,'goToCurrent'))"`
→ `false false false false` (and the same for `tr` and `sr-Latn`).
`node -e "const j=require('./public/locales/en/assets.json');console.log(Object.keys(j.shotGuide).join(','))"`
→ unchanged, `shotTypes,noShots,header,uploadingModal,camera,actions,strip,review,leave`.

**Verify.** `npm run gate` — a locale's missing key cannot fail the gate (nothing asserts key parity
yet; the skill lists that check as one worth adding *later*). Green here means 7.1 broke nothing else.

---

### Step 7.2 — Translate (operator, needs network)

**Touch.** `public/locales/de/assets.json`, `public/locales/tr/assets.json`,
`public/locales/sr-Latn/assets.json` (written by the script)

**Do.**

```
npm run i18n:translate
```

It processes `assets` among the five namespaces, finds the 15 missing keys per language, translates
them in batches of 15 with a 1 s pause, converts `sr-Latn` back from Cyrillic, and rewrites the three
files as two-space-indented JSON. The 15 keys are:
`shotGuide.actions.goToCurrent`, `shotGuide.actions.takePhotoFirst`,
`shotGuide.strip.ariaLabel`, `.pendingItem`, `.capturedItem`, `.currentItem`,
`shotGuide.review.title`, `.description`, `.checklist`, `.submit`,
`shotGuide.leave.title`, `.description`, `.confirm`, `.cancel`.

**Halt** if the run fails on network access and leaves any of the three locales missing keys
(halt condition in the index). Re-run once; if it fails again, report rather than hand-translating
three languages into the plan.

**Accept.**

```
node -e "
for (const l of ['en','de','tr','sr-Latn']) {
  const s = require('./public/locales/'+l+'/assets.json').shotGuide;
  console.log(l, Object.keys(s).sort().join(','), '|', Object.keys(s.review).sort().join(','), '|', s.review.title);
}"
```

→ four lines. The two key lists are identical across all four languages (that is the parity check),
and `s.review.title` differs from `All photos collected` in at least `de`, `tr` and `sr-Latn` — proving
the run replaced the placeholders rather than passing them through.

Also: `git diff --stat public/locales/` → three files changed, `en/assets.json` **not** among them.

**Verify.** `npm run gate`

### Step 7.3 — Close out the documents

**Touch.** `docs/inspection-guide-refactor.md` (edit), `docs/inspection-guide-refactor.decisions.md`
(edit), `docs/inspection-guide-refactor/00-index.md` (edit)

**Do.**

1. In `docs/inspection-guide-refactor.md`: change the line `Status: DRAFT` to `Status: SHIPPED`.
2. In `docs/inspection-guide-refactor.decisions.md`: every row in the Decisions table already reads

3. In `docs/inspection-guide-refactor/00-index.md`: tick every box in "Definition of done" that the

**Accept.** `grep -n "Status: DRAFT" docs/inspection-guide-refactor.md` → no matches.
`grep -c "Status: SHIPPED" docs/inspection-guide-refactor.md` → `1`.
`grep -c "^- \[ \]" docs/inspection-guide-refactor/00-index.md` → the number of Definition-of-done
boxes whose evidence does not exist yet; state that number in the report and why each remains.

**Verify.** `npm run gate`
