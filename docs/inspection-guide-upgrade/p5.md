### Step 5.1 — confirm the six are still unreachable

**Touch.** none. This step does not change the tree — it is the one thing to do *before* deleting, so
that the deletion is evidence-backed rather than remembered.

**Do.** Run the import scan. The script is not committed — write it to a scratch directory outside the
repo and pass the repo path as an argument, because a downloaded or generated script must not be run
from inside the tree it reads.

```js
// C:\Users\Jovan\AppData\Local\Temp\covera-scan\scan.mjs
// Usage: node scan.mjs C:\Users\Jovan\Desktop\bets\covera
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join, relative, sep } from "node:path";

const root = process.argv[2];
const TARGETS = [
  "src/components/Grid.tsx",
  "src/components/Stack.tsx",
  "src/components/LocaleSwitcher.tsx",
  "src/components/host/InlineCamera.tsx",
  "src/components/host/ReservationHeaderActions.tsx",
  "src/components/ConfirmationButton.tsx",
];

const files = [];
(function walk(dir) {
  for (const entry of readdirSync(dir)) {
    const full = join(dir, entry);
    if (statSync(full).isDirectory()) {
      if (entry !== "node_modules" && entry !== ".git") walk(full);
    } else if (/\.(ts|tsx)$/.test(entry)) {
      files.push(full);
    }
  }
})(join(root, "src"));

for (const target of TARGETS) {
  const base = target.slice(target.lastIndexOf("/") + 1).replace(/\.tsx?$/, "");
  const importers = files.filter((file) => {
    if (relative(root, file).split(sep).join("/") === target) return false;
    return new RegExp(`from\\s+["'][^"']*\\b${base}["']`).test(readFileSync(file, "utf8"));
  });
  console.log(base.padEnd(28), importers.length === 0 ? "NO IMPORTER" : importers.map((f) => relative(root, f)).join(", "));
}
```

**Accept.**
- The scan reports `NO IMPORTER` for `Grid`, `Stack`, `LocaleSwitcher`, `InlineCamera` and `ReservationHeaderActions`
- It reports **exactly one** importer for `ConfirmationButton`: `src/components/host/ReservationHeaderActions.tsx`
  — which is itself in the list, so the two form one dead chain and both go (D35)
- `grep -rn "InlineCamera\|ReservationHeaderActions\|LocaleSwitcher" src --include=*.ts --include=*.tsx` → **comments only**, no `import`
- If any of these six has gained an importer since 2026-11-01, **STOP** — that file is out of scope now,
  and deleting it would break the build in a way this plan did not model

**Verify.** none (no change to verify)

```ts

```

`window` stays — it is a different value with its own readers, and its `isPast` field is `proofWindow`'s,

of the delete rule; this phase removes only the second *name* for it.

**Accept.**
