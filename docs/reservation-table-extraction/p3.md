# Phase 3 — the table extraction and the typography

**Prerequisite:** phase 1 (nothing here imports it, but the branch's `tsc` must be clean before this
phase starts). Phase 2 is independent of this phase — the two touch different files.
**Gate:** `npm run gate` (run in `covera`).

This phase is one user-visible thing: `ReservationsTable` is a reusable table, and its text is
uniform.

**The tree does not compile between steps 3.2 and 3.3, by design.** Step 3.1 removes
`onOpenCreateReservation` from the table's props while its only caller still passes it, so `tsc -b`
reports TS2322 until step 3.3 rewrites that call site. Steps 3.1–3.3 are one atomic change split for
readability; a red `tsc` inside that window is expected and is not the halt in `00-index.md`. The
first honest green is at the end of 3.3, and the phase boundary is what the gate must pass.
