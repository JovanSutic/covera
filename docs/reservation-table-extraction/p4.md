# Phase 4 — the copy for a past stay

**Prerequisite:** phase 2 must be complete — this phase adds the four keys phase 2's components
reference (`reservationActionsCell.tooltip.{stayPast,hasInspectionPast,copyMessagePast,cannotDeletePast}`).
**Gate:** `npm run gate` (run in `covera`).

This phase is last because `i18n:translate` copies whatever `en` holds: running it before the
components reference the keys would translate four unused keys and then need a second run.

---

### Step 4.1 — Add the four English tooltips

**Touch.** `public/locales/en/host.json` (edit)

**Do.** In the `reservationActionsCell.tooltip` object, add four keys directly after the existing
`cannotDelete` line, so the delete-related keys stay together and the new past-stay keys read as one
group:

```json
    "cannotDelete": "Cannot delete reservations that have already started",
    "stayPast": "This stay is over, so photo proofs can no longer be taken",
    "hasInspectionPast": "This stay is over, so a new guest inspection link cannot be created",
    "copyMessagePast": "This stay is over, so the guest message is no longer available",
    "cannotDeletePast": "This stay is over, so it can no longer be deleted",
```

Each names the real reason rather than borrowing `cannotDelete`'s wording (D6): a proof action
reading "cannot delete" would be a new bug.

**Accept.** `node -e "const t=require('./public/locales/en/host.json').reservationActionsCell.tooltip; console.log(Object.keys(t).length, ['stayPast','hasInspectionPast','copyMessagePast','cannotDeletePast'].every(k=>k in t))"` → `14 true` (the object had 10 keys before this step)

**Verify.** `npm run gate` — a key present in `en` only is not a gate failure (nothing checks locale
parity), which is exactly what step 4.2 fixes.

---

### Step 4.2 — Translate the four keys into the other three locales

**Touch.** `public/locales/de/host.json`, `public/locales/tr/host.json`,
`public/locales/sr-Latn/host.json` (edit — by the script, not by hand)

**Do.** Run the repo's translation script:

```
npm run i18n:translate
```

It reads `en` as the source and writes `de`, `tr`, and `sr-Latn`, preserving HTML tags and converting
Serbian Cyrillic to Latin (`scripts/translate-locales.ts`). It needs network access to Google
Translate.

**This step is not hand-written.** Do not type German, Turkish, or Serbian: every existing value in
these files is a genuine translation, and hand-written copy would break that convention where a
machine run would not.

**If the script fails** for want of network, that is the plan's halt condition — report the raw output
and stop. Do not leave the three locales without the keys, and do not fill them with the English
strings.

**Accept.** The script's own output reports the `host` namespace synced for `de`, `tr`, and `sr-Latn`.
Then confirm all four keys carry a non-empty value in every locale:

```
node -e "
const ls=['en','de','tr','sr-Latn'];
const ks=['stayPast','hasInspectionPast','copyMessagePast','cannotDeletePast'];
for (const l of ls) {
  const t=require('./public/locales/'+l+'/host.json').reservationActionsCell.tooltip;
  const missing=ks.filter(k=>!t[k]||!String(t[k]).trim());
  console.log(l, missing.length===0 ? 'all 4 present' : 'MISSING '+missing.join(','));
}
"
```

→ four `all 4 present` lines.

**Verify.** `npm run gate`

### Step 4.3 — Confirm the locale sets are still in step

**Touch.** none (a check, not an edit)

**Do.** The script only adds keys, but it rewrites whole files, so the four key sets must still match
exactly. Compare the flattened sets:

```
node -e "
const fs=require('fs');
const flat=(o,p='')=>Object.entries(o).flatMap(([k,v])=>v&&typeof v==='object'?flat(v,p+k+'.'):[p+k]);
const en=flat(JSON.parse(fs.readFileSync('public/locales/en/host.json','utf8'))).sort();
console.log('en', en.length);
for (const l of ['de','tr','sr-Latn']) {
  const ks=flat(JSON.parse(fs.readFileSync('public/locales/'+l+'/host.json','utf8'))).sort();
  const missing=en.filter(k=>!ks.includes(k));
  console.log(l, ks.length, 'missing', missing.length, missing.join(','));
}
"
```

**Accept.** `en` reports **160** keys (156 before this feature, plus these 4), and each of `de`, `tr`,
`sr-Latn` reports the same number with `missing 0`. A different total means the script wrote a partial
file: report it and stop rather than editing a locale by hand.

**Verify.** `npm run gate`
