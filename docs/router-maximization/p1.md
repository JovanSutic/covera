# Phase 1 — session store and baseline

**Prerequisite:** none. This is playbook stage 0 (baseline and measurement) plus stage 1's first half.
**Gate:** `npm run gate` — green on entry (verified 2026-10-27: exit 0, `Tests 4 passed (4)`).

**Why this phase is first:** playbook stage 0 requires the numbers to beat, and stage 1 requires the
session to be loaded once before the router exists. Both are cheap and both are preconditions for
proving anything later.

**Observable gain.** Today the session is read by a TanStack Query that `Header` mounts **on every
page** (`src/hooks/auth.ts` → `getAuthUserFromJwt` → `supabase.auth.getSession`). After this phase it
is read exactly once, before the first render, and every consumer reads that one snapshot. The Header
also stops showing its loading pulse on every navigation.

### Step 1.1 — The session store

**Touch.** `src/lib/router/session.ts` (create)

**Do.**

```ts
import type { AuthenticatedUser, UserRole } from "@/lib/auth";

export interface SessionState {
  status: "loading" | "ready";
  user: AuthenticatedUser | null;
  role: UserRole | null;
}

export interface SessionStore {
  getSnapshot(): SessionState;
  subscribe(listener: () => void): () => void;
  bootstrap(): Promise<SessionState>;
  refresh(): Promise<SessionState>;
}

export interface SessionStoreOptions {
  readUser: () => Promise<AuthenticatedUser | null>;
}

const LOADING: SessionState = { status: "loading", user: null, role: null };

export function createSessionStore({
  readUser,
}: SessionStoreOptions): SessionStore {
  let state: SessionState = LOADING;
  const listeners = new Set<() => void>();

  const emit = () => {
    for (const listener of [...listeners]) listener();
  };

  const load = async (): Promise<SessionState> => {
    const user = await readUser();
    state = { status: "ready", user, role: user?.role ?? null };
    emit();
    return state;
  };

  return {
    getSnapshot: () => state,
    subscribe(listener: () => void) {
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
    bootstrap: load,
    refresh: load,
  };
}
```

`src/lib/router/session.ts` has **no runtime imports** — `src/lib/auth.ts` is imported as a type only,
which `verbatimModuleSyntax: true` erases entirely. That is deliberate: `src/lib/auth.ts` imports
`src/lib/supabase.ts`, which throws when the Supabase env vars are absent, so a runtime import here
would make every router test depend on `.env`. The concrete reader is injected by `main.tsx` in step 1.4.

**Accept.** `grep -c "^import" src/lib/router/session.ts` → `1` (the type-only import), and
`grep -n "import type" src/lib/router/session.ts` → one line importing `AuthenticatedUser` and `UserRole`.

**Verify.** `npx tsc -b` — exit 0.

### Step 1.2 — Session store test

**Touch.** `src/lib/router/session.test.ts` (create)

**Do.**

```ts
import { describe, expect, it, vi } from "vitest";
import { createSessionStore } from "./session";
import type { AuthenticatedUser } from "@/lib/auth";

const HOST: AuthenticatedUser = {
  id: "user-1",
  email: "host@covera.test",
  role: "host",
  firstName: "Host",
  lastName: "User",
};

describe("createSessionStore", () => {
  it("starts loading with no user and no role", () => {
    const store = createSessionStore({ readUser: async () => null });

    expect(store.getSnapshot()).toEqual({
      status: "loading",
      user: null,
      role: null,
    });
  });

  it("maps an anonymous reader to a ready snapshot with no user", async () => {
    const store = createSessionStore({ readUser: async () => null });

    await expect(store.bootstrap()).resolves.toEqual({
      status: "ready",
      user: null,
      role: null,
    });
  });

  it("derives the role from the authenticated user", async () => {
    const store = createSessionStore({ readUser: async () => HOST });

    const state = await store.bootstrap();

    expect(state.status).toBe("ready");
    expect(state.user).toEqual(HOST);
    expect(state.role).toBe("host");
  });

  it("notifies subscribers once per change and stops after unsubscribe", async () => {
    const store = createSessionStore({ readUser: async () => HOST });
    const listener = vi.fn();

    const unsubscribe = store.subscribe(listener);
    await store.bootstrap();
    expect(listener).toHaveBeenCalledTimes(1);

    unsubscribe();
    await store.refresh();
    expect(listener).toHaveBeenCalledTimes(1);
  });

  it("reads the user again on refresh, so a role change is observable", async () => {
    const readUser = vi
      .fn<() => Promise<AuthenticatedUser | null>>()
      .mockResolvedValueOnce(HOST)
      .mockResolvedValueOnce({ ...HOST, role: "admin" });

    const store = createSessionStore({ readUser });

    await store.bootstrap();
    expect(store.getSnapshot().role).toBe("host");

    await store.refresh();
    expect(store.getSnapshot().role).toBe("admin");
    expect(readUser).toHaveBeenCalledTimes(2);
  });
});
```

**Accept.** `npm run gate` → exit 0 and `Test Files  2 passed (2)` / `Tests  9 passed (9)`

### Step 1.3 — The React bridge

**Touch.** `src/lib/router/AppContext.tsx` (create)

**Do.**

```tsx
import { createContext, useContext, useSyncExternalStore } from "react";
import type { ReactNode } from "react";
import type { SessionState, SessionStore } from "./session";

const SessionContext = createContext<SessionStore | null>(null);

export function SessionProvider({
  session,
  children,
}: {
  session: SessionStore;
  children: ReactNode;
}) {
  return (
    <SessionContext.Provider value={session}>
      {children}
    </SessionContext.Provider>
  );
}

function useSessionStore(): SessionStore {
  const session = useContext(SessionContext);
  if (!session) {
    throw new Error(
      "[router] useSession was called outside <SessionProvider>. " +
        "Pass the store created by createSessionStore() to SessionProvider in main.tsx.",
    );
  }
  return session;
}

export function useSession(): SessionState {
  const session = useSessionStore();
  return useSyncExternalStore(
    session.subscribe,
    session.getSnapshot,
    session.getSnapshot,
  );
}
```

`useSyncExternalStore` needs a **stable** `subscribe` reference; `session.subscribe` is a method of the
object returned by `createSessionStore`, and that object is created once in `main.tsx`, so the
reference is stable for the app's lifetime. The third argument (`getServerSnapshot`) is passed so
jsdom and any SSR-shaped test cannot throw.

**Accept.** `grep -c "export function useSession" src/lib/router/AppContext.tsx` → `1`

**Verify.** `npx tsc -b` — exit 0.

### Step 1.4 — Bootstrap before the first render

**Touch.** `src/main.tsx` (rewrite)

**Do.** Replace the entire file with:

```tsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { Toaster } from "sonner";

import App from "./App";
import "./index.css";
import "./i18n.tsx";
import { getAuthUserFromJwt } from "./lib/auth";
import { createSessionStore } from "./lib/router/session";
import { SessionProvider } from "./lib/router/AppContext";

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 15,
    },
  },
});

async function start() {
  const session = createSessionStore({ readUser: getAuthUserFromJwt });

  // One session read, before the router exists. Every access check reads this
  // snapshot synchronously; none of them performs a request.
  await session.bootstrap();

  createRoot(document.getElementById("root")!).render(
    <StrictMode>
      <QueryClientProvider client={queryClient}>
        <Toaster closeButton position="top-center" richColors />
        <SessionProvider session={session}>
          <App />
        </SessionProvider>
      </QueryClientProvider>
    </StrictMode>,
  );
}

void start();
```

Do **not** add a loading screen or a `try/catch` around `bootstrap`: `getAuthUserFromJwt` already
catches its own decode failures and returns `null`, so an anonymous visitor gets a ready snapshot, not
an error. A thrown error here would mean Supabase is misconfigured, which should be loud.

**Accept.** `npm run gate` → exit 0. Plus `grep -n "await session.bootstrap" src/main.tsx` → one line, and `grep -c "createSessionStore" src/main.tsx` → `2` (import + call).

**Verify.** `npm run gate`
